# NSCLK-ESP32 —— 温湿度监控终端

ESP32 + SSD1351（128×128 RGB 彩屏）+ SHT30 + LIS3DH。
由原来的「天气摆件」改造而来：去掉联网和交互功能，改成一块纯监控终端。
它与 RP2040 空气质量终端装在同一个外壳里（无数据交互），视觉风格互相协调、
内容各自独立。

## 拷到板子上的文件（5 个）

| 文件 | 说明 |
|---|---|
| `main.py` | 主程序。只读 SHT30 + LIS3DH，显示委托给 `ui.py` |
| `ui.py` | 界面层，不 import 任何硬件 —— 所以能在电脑上预览 |
| `SSD1351.py` | 驱动。原始版本 + 12×12 中文绘制路径 |
| `font/utf12.bin` | 12×12 中文字集，14 字 / 336 字节 |
| `font/utf12.tab` | 码位表（升序，大端 uint16），28 字节 |

`font/` 下原有文件（font6/font8/digi/icon/boot）都不动。
`bak/` 是改造前的原始快照，不参与运行。

## 相对原版的改动

**删掉的**
- WiFi：原来连天气服务器并用服务器数据**覆盖本地读数**
- WS2812 RGB 灯、BQ24072 充电管理
- 三种手势开关（倾 X 开 WiFi / 倾 Y 开灯 / 倾 Z 息屏）

**改掉的**
- LIS3DH 从手势开关变成**姿态传感器**：HR 模式读 12 位、零偏标定、运动检测、`atan2` 解算 pitch/roll
- 节奏从阻塞式 50 次取样平均（1 秒）改成非阻塞：姿态 50ms / 温湿度 1s 滑窗 / 绘制 160ms 节流

**保留的**
- 开机画面、`led = Pin(45)` 板级初始化
- SHT30 的 `-3.5` / `+11` 偏置 —— 这是**用户标定的系统误差校正**，不是随手写的数

## 局部重绘（消除闪烁的核心）

原来每帧重画整个画面，一帧 176 次 `fill`，每次都是一次独立 SPI 事务；而且
流程是「先铺背景再画内容」，屏幕上就是「刷黑→出现」的闪烁。

现在 `ui.py` 里有一层**变更缓存**：

```python
_paint_cache = {}
def _changed(key, value):     # 内容变了才返回 True
    ...
```

- 静态元素（标签、分隔线、圆环轨道）**只画一次**
- 时间每分钟变一次、温湿度一秒一次，值没变就完全不画
- 水平仪的小球：移动小于 `BALL_STEP`（2 像素）时不重画整块

模拟器实测每帧 `fill` 次数：

| 状态 | 次数 |
|---|---|
| 首帧全画 | 185 |
| **什么都不变** | **0** |
| 只有时间变 | 1 |
| 姿态大变（球移动） | 176 |

## 三条必须遵守的布局约束（都是驱动行为）

1. **底部 12 像素放不下中文**。`prt()` 的越界判断是 `y > 128 - 字高`，成立就
   **清屏回到 (0,0)**。12 高的中文放在 y=120 满足 `120 > 116`，会把整屏擦掉。
   而且是**逐字**判断的，混排字符串中途遇到中文也会清屏。
2. **中文字宽 12px、ASCII(6×8) 是 6px**。排坐标不能混着按 6px 算。
3. **数码管字体里没有空格**。`DIGI_MAP` 只有 `0-9 - . : C %`，落表外会取第 16 个
   字形（一个实心方块）。所以不能用 `%4.1f` 这种补空格的格式化。

另外：**贴右边缘的中文串要用 `prt_cjk()` 而不是 `prt()`** —— 后者画完每个字都
检查换行条件，x 到 104 时第二个字会被折到下一行。

## 姿态解算

**轴映射是三次实机校准的结果，不能按数据手册推**（手册的轴向和实际装配无关）：

| 修正 | 依据 |
|---|---|
| Z 轴取反 | 设备正常摆放时读数是 `(0, 0, -1.02)` |
| X/Y 互换 | 左倾时小球上下跑 |
| roll 取负 | 上下对了、左右反了 |

处理链：**减零偏 → 运动检测（模长偏离 1g 超过 `MOTION_G` 就冻结）→ 指数平均（`ATT_ALPHA`）**

**为什么不上卡尔曼**：LIS3DH 只有加速度计没有陀螺仪，没有第二个独立测量源可融合，
滤波器会退化成低通 —— 那正是现有指数平均在做的事，而每样本的浮点矩阵运算在这个
板子上是纯开销。

**精度上限**：单加速度计**无法区分「倾斜」和「水平 + 横向加速」**（0.2g 横向加速度
和 11° 倾斜在加速度向量上完全相同）。竖直颠簸能用模长检测挡掉，横向挡不掉。
实际精度约 ±2~3°，碰桌子会有几度假倾角然后慢慢回正。要根本改善需要加陀螺仪。

## 预览与检查（电脑上跑，与设备无关）

```powershell
$env:PYTHONIOENCODING = "utf-8"
python preview\ssd1351_sim.py      # 模拟器自检 + 能力测试图
python preview\check_sync.py       # 驱动 ↔ 模拟器结构是否一致
python preview\check_layout.py     # 布局溢出/重叠/残留/标签存在性
python preview\mock_ui.py          # 渲三版方案图
python tools\make_cjk.py           # 重新生成 font/utf12.*（字集从 ui.ZH_CHARS 读）
```

`preview/ssd1351_sim.py` 模拟的是**显存 + 寻址窗口 + 流式写入**，连 `__rgb_565__`
的 5-6-5 截断（不是四舍五入）、`pos()` 的 `& 0x7F` 回绕、`bwp()` 的分段行为都照抄。

**`check_sync.py` 为什么重要**：驱动和模拟器是同一套算法的两份实现。这个项目里
已经因为「只改一边」出过真机 bug。改完任一边都跑一下。

**`check_layout.py` 的四类判据**：状态带不溢出 / y=12 是完整分隔线 / 标签与数字不重叠 /
**连续 N 帧后与全新绘制比对无残留** / 标签区域内必须有内容。

⚠️ 残留检查必须用**恒定姿态**：小球的移动量化是设计代价，姿态变了会让「运行中的
球位」和「全新绘制的球位」差几个像素，那不是残留。

## 界面

三版布局都在 `ui.py` 里，`LAYOUT` 一行切换，默认 **B 左右分栏**：

| 方案 | 结构 |
|---|---|
| A 上下分栏 | 上半温湿度，下半水平仪 |
| **B 左右分栏（默认）** | 左列温湿度竖排，右列水平仪 |
| C 卡片式 | 顶部状态栏 + 两块卡片 |

共同部分：顶部 12 像素状态栏（闪烁状态点 · 运行 h:mm · 姿态状态）、温度色阶
（≤0 蓝 / ≤16 绿 / ≤26 琥珀 / ≤31 橙 / 其余红）、小球水平仪、底部 pitch/roll 数值。

改界面用字**必须同步改 `ui.ZH_CHARS`** —— 中文是子集，表外的字画不出来
（`cjk()` 查不到就什么都不画）。
