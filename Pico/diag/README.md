# 诊断 / 对照文件

这些文件**不参与正式运行**，`main.py` 不会 import 它们。留着是为了以后排查。

| 文件 | 用途 |
|---|---|
| `diag_uart.py` | 三路串口原始字节打印。接新传感器时先跑它，看帧头和数据是否正确 |
| `main_nohcho.py` | 加甲醛之前的 main 结构，用于 A/B 对照 |
| `EnvSensor_orig.py` | 加超时和 get_ch2o 之前的 EnvSensor，用于 A/B 对照 |

用法：拷到设备上（诊断脚本直接跑；对照文件要改名成 `main.py` / `EnvSensor.py`）。

## 已经踩过的坑（诊断时的经验）

- **建 `UART(1)` 不指定 tx 会导致花屏**：RP2040 上 UART1 省略 tx 会回落到
  默认引脚 GPIO8，而 GPIO8 是显示总线的 sideset base。表现为"坐标系全乱、斜条纹"。
- **BOOT 画面正常、进主循环就花** = 先怀疑启动代码里有没有动过显示引脚或主频。
- **部分元素正常、部分乱** = 更可能是硬件/时序，软件故障通常是一致的。
